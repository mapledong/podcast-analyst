## Key Facts

> **F1** Cost prints: Uber issued employee token stipends, then pulled them — four months blew the annual AI budget. Meta is planning limits on remote-work token burn. A NAS-drive / infra team Hongjun visited puts 'Opus 4.5 is expensive, save cost, start with other models' on the internal model picker. Huang (or Zhang) on last November's hardest-software-with-the-best-agent phase: $400–500/day, $140k already, and that was still on Claude Code Pro Max. The open question is whether maximizing tokens / always-strongest-model is still the market answer.

> **F2** OpenClaw vs Hermes: Peter shipped OpenClaw in about a week. Zhang reads that as the model crossing a bar — an experienced architect can stand up a system fast, including Huang's line that three months can yield a most-complex distributed database. OpenClaw is the bazaar: anyone dumps ideas, Peter does not even review, 'Agent says it's fine.' Stability and code quality are the complaint. Hermes is a designed architecture: better onboarding, more reflection, it turns successful runs into Skills so the loop grows best practices. OpenClaw generalized Claude Code / Codex (agentic loop + tools) to a lower consumer door.

> **F3** Cheap smart models: DeepSeek, GLM, and Kimi are near first tier; Valley shops are wiring them in. Huang is first angel and early user of Slug (Kimi CLI, You Kaichao / 钱与超; later renamed — he still says Slug), a Slack-for-agents channel. Local stack on the tape: DeepSeek V4 and Zhipu GLM 5.2. The management metaphor: you do not staff a company with only Zhang-class seniors — frontier model plus cheap open model is the org chart. Close: Keep building / get hands on. Research → engineering, model → agent.

OpenClaw proves a week of architecture can ship a consumer agent loop; Hermes is the productized skill-writing version. Slug/Kimi CLI is the multi-agent Slack. Hands-on beats waiting until you have studied enough.

Do not underwrite 'always Claude Opus' seats. Diligence OpenClaw-class bazaars on review; Hermes-class on whether Skills actually compound. PingCAP's three-month DB line is a capability print for agents, not a TiDB model.
