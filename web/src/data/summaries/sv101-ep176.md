## Key Facts

> **F1** Culture: founders rage if a $500k engineer spent only ≈$5k tokens; others call raw token volume a bad KPI (Jellyfish CEO). Consensus middle: under-using AI loses. OpenClaw-class agents jump spend from 10ks to millions of tokens; Claude for tiny tasks can cost $10–20.

> **F2** China angle: on some tasks US–China price gaps 50–70x; MiniMax recommended inside OpenClaw setup; Zhipu/MiniMax equities ripped as open-model calls surged. March 2026: Tencent/Alibaba/Baidu cloud AI prices up ≈30% in ≈10 days after open-model token demand crossed a capability threshold.

> **F3** Stack: routers + agent products (Genspark/Manus) assign hard/easy tasks to minimize cost; Metronome separates usage event streams from pricing/contracts. Macro metaphor: London dev hitting MiniMax burns China grid power locally while value settles as API — 'power export' without customs. Durability of cheap tokens questioned as capacity queues appear.

## Key Insights

> **1.** Tokens became corporate status and P&L at once.
>
> **Q** Is maxxing rational?
>
> **A** As culture maybe; as KPI often waste — but zero usage is competitive suicide.

> **2.** China sells cheap inference into agent demand.
>
> **Q** Why OpenRouter dominance?
>
> **A** Good-enough instruction following at 50–70x lower price when agents burn millions of tokens.

> **3.** Token export is electricity export by another name.
>
> **Q** Is the discount durable?
>
> **A** Only while power/capacity and open-model gaps persist; March cloud hikes are the tell.
